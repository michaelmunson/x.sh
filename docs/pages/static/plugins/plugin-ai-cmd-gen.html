x.sh

Plugins>ai-cmd-gen

Generate a shell command from natural-language instructions, edit it in your shell, then run it. Source the shell wrapper so x() can intercept -A / --ai:

x -i --plugin ai-cmd-gen
source <(x --plugin ai-cmd-gen __wrapper)

x --ai --config               # configure ~/.x.sh/config/llm.sh
x -A "list the 10 largest files here"
x --ai find all rust files modified today
x -A                          # prompts for instructions when omitted
Shell startup: Add source <(x --plugin ai-cmd-gen __wrapper) to ~/.bashrc or ~/.zshrc so -A / --ai work in every session. Without the wrapper, those flags are not intercepted.

LLM provider

If the LLM provider is not configured, generation fails with a message to run x --ai --config. That opens your editor on ~/.x.sh/config/llm.sh. The script must accept the prompt as $1 and print the completion to stdout.

llm.sh example 
#!/bin/bash
PROMPT="$1"
ollama run llama2 "$PROMPT"

Flow

  1. The plugin calls ~/.x.sh/config/llm.sh with a shell-specific system prompt plus your instructions.
  2. The generated command is shown for editing (read -e in bash, vared in zsh).
  3. The command is added to shell history, then eval'd.

Direct plugin invocation

You can call the plugin without the shell wrapper (prints the command to stdout; does not edit or eval):

x --plugin ai-cmd-gen --config
x --plugin ai-cmd-gen --shell zsh list files by size
  • --config: create/edit ~/.x.sh/config/llm.sh.
  • --shell bash|zsh: target shell dialect for the generated command (defaults from $SHELL).
  • <instructions…>: natural-language description of the desired command.
