x.sh

Quick Start

1. Create your first script

x --init hello-world
# or: x -i hello-world

Interactive prompts ask for the script name (alphanumeric + dashes), an optional description, and a programming language. Your $EDITOR opens so you can write the script body.

2. Run it

x hello-world
x hello-world arg1 arg2   # args pass through to the script

3. List installed scripts

x --ls
# or: x -l

Shows a formatted table with name, description, language, groups, and last-run timestamps.

4. Add to PATH (optional)

x --ln hello-world
# Now run directly: hello-world

5. Project-local commands (optional)

Drop an x.yml in your project root to define repo-specific tasks. Commands are dot-prefixed keys (a string is shorthand for an inline script):

x.yml 
.test: npm test

.build:
  args: <version>
  $: |
    npm run build
    echo "Built $(x-arg version)"
x test
x build v1.0.0
