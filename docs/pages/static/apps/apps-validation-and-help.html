x.sh

Apps>Validation & Help

Automatic help

Every command supports -h / --help out of the box, with no extra configuration.

x my-app --help
x my-app build --help
x my-app create file --help

Non-leaf commands without their own $: auto-print help when invoked bare. The same renderer powers x-usage <cmd-path> inside scripts, so you can print context-appropriate help from bash.

Save-time validation (x -i --app)

When you finish editing an app file, x performs a full structural check:

  • YAML parses cleanly.
  • Removed v3 syntax: a commands: mapping, or a top-level $: used as a handler map.
  • Every synopsis string parses into a valid spec.
  • Leaf commands have a $: script or an alias:.
  • Script keys (inline or imported) match a defined command path.
  • alias: commands don't also define options/arguments/dir/env/$/subcommands.
  • No duplicate options or arguments within a command.
  • No dangling requires: references.
  • No conflicting help/description, options/opts, or arguments/args on the same node.
  • $.import and import.$ are not both present.

On failure, x lists all errors and offers edit (re-open the editor) or revert.

Runtime validation

A lighter validation pass runs on every x <app> / project x.yml invocation so hand-edited or stale files fail fast with readable errors before any bash executes.
