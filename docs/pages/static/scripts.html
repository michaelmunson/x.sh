x.sh

Global Scripts

Global scripts are plain files in ~/.x.sh/scripts/. Each script is executed with the program stored in its metadata (or the global default from x --config).

Creating and editing

x -i is the primary workflow. x opens your $EDITOR, and on save, writes the file and metadata.
Re-running x -i <name> on an existing script lets you edit in place or rename.

Passing arguments

# Script: curl-google (bash)
curl -s "https://google.com$1"

$ x curl-google /search
# → curl -s "https://google.com/search"

Program / interpreter

The program field in metadata determines how x invokes the file, such as bash, python, node, go run, etc. Set per-script during x -i or rely on the global default.

Groups

Metadata groups are free-form tags for organization. They appear in x --ls output to help you scan large script collections.

Symlinks vs scripts

x --ln creates a symlink in ~/.local/bin/, not a copy. The symlink points at the script file in ~/.x.sh/scripts/, so edits via x -i are reflected immediately.
